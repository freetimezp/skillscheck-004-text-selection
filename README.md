# Skills Check 004 — Custom Text Selection

A beginner-friendly interactive assessment for CSS custom text selection, the `::selection` pseudo-element, and accent colors.

## Features

- 20 questions covering CSS selection styling
- Randomized question order
- Randomized answer option order
- Single-answer and multiple-answer questions
- Code-reading and CSS debugging challenges
- Instant feedback with explanations
- Progress tracking and final score
- Restart with a fresh randomized attempt
- Responsive layout for desktop, tablet, and mobile
- Keyboard-accessible answer controls
- Reduced-motion support
- No frameworks or external JavaScript libraries

## Topics covered

- `::selection` syntax and selector scope
- `color` and `background-color`
- CSS custom properties and `var()`
- Color contrast and readability
- Supported properties and limitations
- Pseudo-elements versus pseudo-classes
- Debugging CSS declarations

## Run locally

Open `index.html` in your browser.
